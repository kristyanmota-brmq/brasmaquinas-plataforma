## 5. Achados

### H1 — Toggle do drawer mobile sem `aria-expanded`

- **Severidade:** menor (acessibilidade)
- **Diagnóstico:** `browser_evaluate` em ambos os estados (drawer aberto / fechado) retornou `toggleAriaExpanded: null`. Leitores de tela não sabem se o painel está aberto.
- **Recomendação:** task **D** futura — adicionar `aria-expanded={drawerOpen}` no botão. Escopo ≤ 5 linhas em `src/components/map/ProjectMap.tsx`.

### H2 — Ambiente precisa de fixtures pré-criadas

- **Severidade:** processo
- **Diagnóstico:** Cenários 2-5 dependem de projetos específicos (com blocker, com 2/3/4 setores). Hoje o banco só tem Projeto A.
- **Recomendação:** task **E** ou **D** de **seed de fixtures**:
  - 1 projeto fictício com bomba HMT insuficiente → blocker `pump_insufficient_head` → testa Cenário 2.
  - 3 projetos fictícios pequenos com área/jornada calibradas para 2, 3, 4 setores → testa Cenários 3-5.
  - Implementação via `prisma/seed.ts` ou script admin.

### H3 — Canvas Mapbox WebGL bloqueia automação de desenho

- **Severidade:** infraestrutura
- **Diagnóstico:** o fluxo "novo projeto" depende de cliques precisos em coordenadas geográficas dentro do canvas Mapbox para desenhar polígono e captação. Playwright `browser_click` só envia coordenadas viewport-relativas para o canvas, que recebe os eventos como pixel click — mas a tradução para `mapboxgl.LngLat` interna depende de cada implementação. Sem hook programático (`map.fire('click', { lngLat })` exposto), automação é inviável.
- **Recomendação:** considerar criação programática via Prisma (seed) OU endpoint admin que aceita GeoJSON + parâmetros (sem UI). Fora do escopo desta task; relacionado a H2.

### H4 — Cenário 6 confirmado positivo (não é bug)

- **Severidade:** confirmação
- **Diagnóstico:** Projeto A confirmado com 17 laterais físicas divididas via texto na sidebar + regex DOM + screenshot. Labels visualmente distribuídos sobre as sub-colunas no ângulo 59° (TASK-046). Nenhuma evidência de concentração indevida ou fallback ao centroide.
- **Recomendação:** nenhuma ação corretiva. TASK-014 fica visualmente validada para o caso "coluna fragmentada" — falta apenas validação 2/3/4 setores (Cenários 3-5) para fechar TASK-014 inteira.
