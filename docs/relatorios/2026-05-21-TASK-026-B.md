# Relatório TASK-026-B — Bloquear emissão quando HMT ou cálculo hidráulico essencial estiver indefinido

**Status:** Concluída

---

## O que foi feito

Adicionado gate de emissão em `generateProposalDiagnostics()` (em `src/lib/bom.ts`) que produz blocker quando o projeto está completo (`isComplete === true`) mas a hidráulica essencial está ausente, inválida ou estruturalmente inconsistente. Derivado do achado A-2 da TASK-026: na validação sintética, o sistema permitia emissão de PDF mesmo com `secondaries = []` e `hydraulics` parcial. A causa-raiz (achado A-1) não foi tocada — pertence à TASK-026-A.

`pdfEmissionBlockers()` permanece passthrough puro (`result.diagnostics?.blockers ?? []`). Toda a lógica está em um único ponto de geração dentro de `generateProposalDiagnostics()`.

## Decisões tomadas

| Decisão | Alternativa descartada | Motivo |
|---------|----------------------|--------|
| Gate em `bom.ts` (`generateProposalDiagnostics`) | Gate em `irrigation-project.ts` (`pdfEmissionBlockers`) | Preserva passthrough puro de `pdfEmissionBlockers`; mantém todos os blockers em um único ponto de geração |
| Critério HMT composto (`!hydraulics || !Number.isFinite(x) || x <= 0`) | Apenas `=== undefined` | `totalHMT` é tipado como `number` mas pode ser `NaN`/`Infinity`/`0` em runtime — critério estrutural cobre todos os estados inválidos |
| Usar `sizedSecondaries.length` em vez de `secondaries.length` | Passar `secondaries` como novo parâmetro | `generateProposalDiagnostics` já recebe `hydraulics`; `sizedSecondaries` tem 1:1 com `secondaries`; evita mudança de assinatura |
| Distribuição checa apenas quando HMT válida (`else` branch) | Checar independentemente | Evita duplicar blocker quando `hydraulics === null`; distribuição é sub-issue de HMT |
| Estender filtro do otimizer (4 linhas) | Reverter gate / acomodar com refactor maior | Mesma lógica do filtro `"BOM incompleta"` já existente — blockers de cálculo incompleto não são violações hidráulicas reais; mudança surgical alinhada ao padrão |

Nenhuma decisão arquitetural significativa. Todas seguem padrões já estabelecidos no codebase.
