## O que foi feito

### TASK-007 — Localizar projeto por endereço ou coordenadas no mapa

Adicionada barra de busca geográfica ao mapa. O usuário pode digitar um endereço ou
coordenadas decimais; o mapa voa para o ponto e exibe um marcador temporário laranja.
A ação "Usar como captação" replica exatamente o fluxo existente de clique no modo captação
(incluindo `queryElevation` e `reverseGeocode`) — nenhum bypass introduzido. Captação só
é salva após confirmação explícita do usuário.

**Arquivos criados:**

- `src/lib/layout/geo-utils.ts` — função pura `parseCoordinate(input): ParseCoordinateResult`;
  detecta e valida lat/lng decimais com ponto como separador decimal; rejeita texto livre;
  marca vírgula decimal brasileira como pendência futura
- `src/lib/layout/__tests__/geo-utils.test.ts` — 13 testes unitários (formatos válidos,
  limites lat/lng, texto livre, pendência documentada); nenhuma chamada à API real do Mapbox
- `src/components/map/MapSearchControl.tsx` — painel flutuante com input de busca,
  aviso operacional ("Localização aproximada — validar antes de avançar"), mensagem de erro
  diferenciada para endereço não encontrado vs. falha de rede/API, botão "Usar como captação"
  visível somente após localização encontrada
- `.env.example` — criado (não existia); documenta `NEXT_PUBLIC_MAPBOX_TOKEN`, `CLERK_*`,
  `DATABASE_URL`

**Arquivos modificados:**

- `src/components/map/ProjectMap.tsx`:
  - Importa `Search`, `MapPin` de lucide-react e `MapSearchControl`
  - Estados `showSearch: boolean` e `searchMarker: { lng; lat } | null`
  - `handleLocationFound` — voa para o ponto via `mapRef.current?.getMap()?.flyTo()` e seta
    `searchMarker`
  - `handleUseAsWaterSource` — replica o bloco `mode === "water"` integralmente
    (`queryElevation` + `reverseGeocode` + `setLayout` + `setMode("view")`)
  - `useEffect` limpa `searchMarker` e `showSearch` quando `mode !== "view"`
  - ToolButton "Localizar" (ícone `Search`) na barra de ferramentas
  - Marcador temporário `<Marker>` com `MapPin` laranja quando `searchMarker !== null`
  - Painel `<MapSearchControl>` renderizado quando `showSearch === true`
