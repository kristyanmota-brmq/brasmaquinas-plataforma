## 4. Decisões editoriais (anti-duplicação)

| Decisão | Como evita duplicação |
|---|---|
| Bullets curtos, sem parágrafos | Cada campo ≤ 5 bullets de uma linha; sem prosa explicativa. |
| Citações por ID | ADRs (ADR-001..015) e premissas (`12-premissas-...md`) citadas por ID + 1 linha de hook. |
| Métricas comparáveis, não números | Números (HMT, BOM, contagem) ficam no relatório TASK-046; aqui só indicadores. |
| Tasks vinculadas = lista plana de IDs | `TASK-XXX, TASK-YYY` sem título/data/resumo. Backlog continua canônico. |
| Status real = nível + evidência | 1 linha aponta para relatório/ADR; auditoria detalhada vive na Seção 10. |
| Sem reescrita das Seções 10/11 | Auditoria (TASK-024C) e matriz (TASK-024D) preservadas integralmente. |
