## Decisões tomadas

| Decisão | Alternativa descartada | Motivo |
|---------|----------------------|--------|
| Fonte primária: `col.selecao.tubo.diametroMm` | Só `sizedSecondaries` | Laterais são sempre dimensionadas; `sizedSecondaries` é opcional (pode estar ausente) |
| Fallback: `sizedSecondaries` | Nenhum fallback | `sizedSecondaries` pode existir sem lateral correspondente; mapa explícito evita duplicação |
| Agrupamento por SKU antes do push | Um item por CP | BOM prática: 3 registros do mesmo SKU devem aparecer como 1 linha com `quantidade: 3` |
| `registrosManuaisSecaoCount = valvulasResolvidasCount` | Campo separado com lógica própria | Na versão atual são equivalentes; campo explícito documenta intenção e facilita extensão futura |
| Warning para acionamento manual (não blocker) | Blocker | Registro manual é operacional válido — a proposta PODE ser emitida, apenas com nota ao campo |
| Blocker residual quando `valvulasSemCatalogoCount > 0` | Sem blocker | DNs sem SKU aprovado ainda não têm preço; emitir proposta com valor incompleto é proibido pela governança |

## Pendências abertas

- [ ] **Catálogo de válvulas automáticas** — `section_valve` com acionamento automático
  (solenoide, hidráulico, elétrico) não possui catálogo nem lógica de seleção. Enquanto não
  houver catálogo aprovado, qualquer CP que exigir controle automático continuará gerando
  blocker. Tarefa futura deve incluir: família, DN, PN, SKU, preço e seletor por diâmetro/tipo.

- [ ] **SKUs para diâmetros sem registro manual primário** — DNs como 40, 60 ou 125 mm não têm
  entrada `prioridade: "primario"` em `REGISTROS_SECAO_MANUAL`. Se o dimensionamento lateral
  resultar nesses valores, `selectRegistroSecao` retorna `undefined` e
  `valvulasSemCatalogoCount` cresce. Ampliar `REGISTROS_SECAO_MANUAL` conforme a Brasmáquinas
  homologar SKUs para esses diâmetros.

- [ ] **Validação de controle automático** — não há flag nem tipo distinto para `section_valve`
  que exige abertura/fechamento automático vs. operação manual. Quando o campo demandar controle
  automático, será necessário: (a) modelar o requisito no CP; (b) criar catálogo separado;
  (c) emitir blocker exclusivo enquanto sem catálogo aprovado.

- [ ] **Distinção entre registro manual e válvula hidráulica automatizada** — na BOM atual,
  `section_valve` resulta em registro VIQUA soldável (operação manual). Uma válvula hidráulica
  automatizada (p.ex. BERMAD) é um produto diferente em preço, instalação e operação.
  Tarefa futura deve separar os dois tipos no modelo de dados antes de adicionar hidráulicas
  ao catálogo, para evitar seleção incorreta pelo motor.

- [ ] **Transição `section_valve` → `resolved`** — `ControlPoint.status` permanece `"pending"`
  mesmo após resolução na BOM. Implementar quando `pendingControlPointsCount` precisar
  distinguir "sem SKU" de "com SKU, aguarda montagem em campo".
