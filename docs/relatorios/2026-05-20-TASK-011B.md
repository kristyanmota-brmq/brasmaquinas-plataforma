## Conteúdo do ADR-009

10 decisões registradas:

| # | Decisão |
|---|---------|
| 1 | Separação de funções: `findBestSprinklerLayout` (geométrico) e `runTopKHydraulicValidation` (hidráulico) |
| 2 | Validação hidráulica somente por ação explícita do usuário |
| 3 | Uso exclusivo do solver oficial `calculateIrrigationProject()` |
| 4 | Proibição de solver hidráulico paralelo (`estimateHydraulicBlockers` não deve ser criado) |
| 5 | `TOP_K_HYDRAULIC_CANDIDATES = 5` como premissa provisória de mercado |
| 6 | `best` após validação restrito aos candidatos Top K avaliados |
| 7 | `jornadaHoras=9` como placeholder técnico sem impacto hidráulico |
| 8 | `geodetic` ausente gera warning, não blocker |
| 9 | `WEIGHT_HYDRAULIC_BLOCKER = 0.50` como premissa provisória |
| 10 | Pendência de revisão futura pela Brasmáquinas |

3 alternativas descartadas documentadas:
- Solver hidráulico leve paralelo (`estimateHydraulicBlockers`) — cria dois modelos divergentes
- Rodar solver em todos os 112 candidatos — custo computacional desproporcional
- Avaliação automática após geométrico — viola separação explícita, quebra sem bomba
