## Decisões tomadas

| Decisão | Alternativa descartada | Motivo |
|---------|----------------------|--------|
| `WEIGHT_SECONDARY_LENGTH = 0.10` e `WEIGHT_TOTAL_NETWORK_LENGTH = 0.10` (ativos) | Manter pesos em 0 por falta de calibração RT | Nova regra de desenvolvimento: quando faltar dado da Brasmáquinas, usar premissa provisória de mercado/engenharia marcada para revisão; não deixar em 0 sem motivo metodológico explícito |
| `try/catch` silencioso no bloco de rede | Propagar exceção | `generatePrincipalAndAdutora` emite `console.warn` para captação dentro do range Y da grade; com 112 candidatos geraria 112 warnings; falha → métricas null, sem bloqueio do score principal |
| Normalização relativa `distributionLengthRatio = (principal + adutora + ramais) / max(laterais, 1)` | Comprimento absoluto de rede | Comprimento absoluto não escala entre polígonos de tamanhos diferentes; razão adimensional é comparável entre todos os candidatos do mesmo polígono |
| `turf.length(turf.lineString(coords), { units: "meters" })` | Função `polylineLengthM` interna de `irrigation-project.ts` | `polylineLengthM` é privada e não está acessível; `turf` já importado no arquivo |
| Comprimento geométrico como proxy (sem solver hidráulico por candidato) | Chamar `calculateIrrigationProject` por candidato | Solver completo por candidato multiplicaria o tempo de cálculo por ~112×; comprimento geométrico é proxy razoável para triagem inicial |
