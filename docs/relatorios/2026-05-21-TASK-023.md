## Decisões tomadas

| Decisão | Alternativa descartada | Motivo |
|---------|----------------------|--------|
| Acumulador `Map<sku, qty>` para agrupamento de kit antes de emitir itens | Emitir item por coluna e deixar UI agrupar | Agrupamento na BOM é responsabilidade do domínio; UI é read-only do resultado |
| Blocker com prefixo `"BOM incompleta — DN de lateral não homologado..."` | Texto sem prefixo "BOM incompleta" | Optimizer filtra blockers comerciais pelo prefixo `b.startsWith("BOM incompleta")`; novo prefixo é compatível automaticamente |
| `custo: 0` com tipo `0` (literal) na interface | `custo?: number` opcional | Força explicitação do dado ausente; previne uso acidental para margem; TypeScript garante `0` é o único valor aceito |
| Trava de segurança na BOM para DN100, sem alterar seletor hidráulico | Remover DN100 de `TUBOS_PVC_LF` ou bloquear no `generatePhysicalColumns` | Alteração do seletor hidráulico tem impacto maior e requer TASK dedicada (TASK-025); trava de BOM é segura e imediata |
| `marca: ""` para SKUs sem fornecedor explícito (`1819000`, `1000843`, `1000354`) | Usar "Tigre" por inferência | Não inventar dado não fornecido pelo RT; campo registrado como pendência documental |
