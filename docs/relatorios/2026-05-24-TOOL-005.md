## 1. Resumo executivo

TOOL-005 introduz a **primeira camada de subagents Claude Code** no repositório Brasmáquinas Plataforma — 4 subagents auxiliares em `.claude/agents/` que reduzem repetição em tarefas de governança **sem substituir** os slash commands obrigatórios (`/iniciar-task`, `/planejar`, `/implementar`, `/fechar-task`) nem a aprovação humana.

A política permanente que rege subagents está consolidada em **ADR-016**. As 8 invariantes (não substituir commands; não decidir criticamente; não relaxar blocker; não alterar premissa RT; não inventar SKU; não promover épico; não auto-commit; não editar `.claude/settings.local.json`) são protegidas mecanicamente por permissões restritivas via campo `tools` no frontmatter YAML + 7 testes estruturais (T-AGT-1..7) integrados ao runner de tooling.

**Invariante crítica isolada (T-AGT-7):** `close-commit-agent` **NÃO** tem `Bash` em `tools` — é mecanicamente impossível executar `git add/commit/push`. O Claude principal roda os comandos git e passa o output ao agente, que apenas PROPÕE staging e mensagem como TEXTO.

**Resultado:** vitest **887/887** (preservado) · tsc **0 erros** (preservado) · **tooling 27/27 → 34/34** (+7 testes T-AGT). Nenhum diff em `src/`, catálogo, PDF, mapa, premissas, ADRs técnicos, tasks técnicas ou comandos existentes.

**Descoberta importante** durante `/fechar-task`: os subagents recém-criados **não estão disponíveis no registry desta sessão** — Claude Code carrega o registry de subagents na inicialização da sessão. Smoke test "live" via tool `Agent` requer reload da sessão (pendência registrada para próxima sessão pós-commit). Validação estrutural mecânica via testes T-AGT-1..7 cobre as invariantes; smoke "live" validará comportamento end-to-end.

## 5. Smoke tests — descoberta e mitigação

### 5.1 Smoke test "live" via tool `Agent` — adiado por limitação técnica

O plano e o `/fechar-task` previam invocação real dos 4 agentes via tool `Agent` para validar comportamento end-to-end:

- T-AGT-Smoke-1 (`context-gate-agent`): auditar TOOL-005 e verificar que apenas reporta
- T-AGT-Smoke-2 (`task-planner-agent`): produzir draft fictício e verificar formato + frase de proteção
- T-AGT-Smoke-3 (`test-qa-agent`): rodar testes e relatar contagens reais
- T-AGT-Smoke-4 (`close-commit-agent`): receber output git fictício e verificar que apenas PROPÕE (recusa execução)

**Resultado das invocações nesta sessão:**

```
Agent({ subagent_type: "context-gate-agent", ... })
→ Error: Agent type 'context-gate-agent' not found. Available agents: claude, claude-code-guide, Explore, general-purpose, Plan, statusline-setup

Agent({ subagent_type: "task-planner-agent", ... })
→ Error: Agent type 'task-planner-agent' not found. (mesma lista)

Agent({ subagent_type: "test-qa-agent", ... })
→ Error: Agent type 'test-qa-agent' not found. (mesma lista)

Agent({ subagent_type: "close-commit-agent", ... })
→ Error: Agent type 'close-commit-agent' not found. (mesma lista)
```

**Causa-raiz:** Claude Code carrega o registry de subagents (`.claude/agents/`) na inicialização da sessão. Como os 4 arquivos foram criados durante esta sessão (`/implementar`), o registry desta sessão não os reconhece. Comportamento esperado da CLI — não falha da implementação.

**Mitigação:**
1. **Validação estrutural mecânica (passou 34/34 nesta sessão)** — T-AGT-1..7 garantem invariantes nos arquivos (existência, frontmatter válido, permissões restritas, frase de proteção, README cobre todos, close-commit sem Bash). Esta validação substitui parcialmente o smoke "live" ao garantir que os PROMPTS e PERMISSÕES estão corretos no disco.
2. **Smoke "live" adiado para próxima sessão pós-commit** — registrado em §pendências do task file e na próxima task sugerida (§7). Após reload, invocar os 4 agentes e anexar outputs em apêndice ao relatório.
