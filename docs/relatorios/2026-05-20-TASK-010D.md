## O que foi feito

### TASK-010D — Métricas operacionais de setorização no motor de candidatos de layout

Evoluiu `findBestSprinklerLayout()` para calcular métricas operacionais de setorização quando o parâmetro `nSetores` é fornecido e válido. As métricas são obtidas via `buildSectorsByFlowWithColumnSplitting()` (já existente em `sectorization.ts`) e integradas ao score de cada candidato como penalidade adicional. A UI exibe as métricas quando disponíveis, ou instrui o usuário a selecionar uma jornada.

**Arquivos modificados:**

- `src/lib/layout/sprinkler-grid-optimizer.ts`:
  - `LayoutScore` estendido com 6 novos campos `number | null`: `operationalSegmentsCount`, `sectionValveCount`, `fragmentedColumnCount`, `fragmentedLateralRatio`, `maxSegmentsPerColumn`, `desbalanceamentoPercent`
  - `OPTIMIZER_PARAMS` com 3 novos pesos marcados `PENDENTE_CALIBRACAO_RT_CAMPO`: `WEIGHT_SECTION_VALVE: 0.3`, `WEIGHT_FRAGMENTATION: 0.4`, `WEIGHT_IMBALANCE: 0.2`
  - Nova função pura `validateNSetores(nSetores, sprinklerCount): number | null` — valida inteiro, >0, ≤ sprinklerCount
  - `computeScore` executa `buildSectorsByFlowWithColumnSplitting` quando `nSetores` é válido e adiciona `operationalPenalty` ao score
  - `buildSelectionReason` inclui seção de métricas operacionais com aviso "preliminares — não substituem validação hidráulica" quando disponíveis, ou aviso de jornada pendente quando não
  - `findBestSprinklerLayout(polygon, spacingMeters, nSetores?: number | null)` — parâmetro opcional retrocompatível

- `src/lib/layout/__tests__/sprinkler-grid-optimizer.test.ts`:
  - 12 novos testes no describe "findBestSprinklerLayout — métricas operacionais com nSetores"

- `src/lib/layout/__tests__/optimizer-integration.test.ts`:
  - Fixture `makeCandidate` atualizada com os 6 novos campos `null` no `LayoutScore` (TypeScript exigia)

- `src/components/map/ProjectMap.tsx`:
  - `runOptimizer` passa `layout.sectorization?.setoresCount ?? null` como `nSetores`
  - Painel do candidato exibe 4 métricas operacionais (registros de seção, colunas fragmentadas, percentual de fragmentação, desbalanceamento) com label "Métricas operacionais — preliminares" quando disponíveis, ou hint "Selecione uma jornada para incluir métricas operacionais." quando null
