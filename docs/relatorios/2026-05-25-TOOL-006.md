## 1. Resumo executivo

TOOL-006 adiciona **11 novos subagents Claude Code** em `.claude/agents/` como camada **opcional e aditiva** de revisão técnica, planejamento e auditoria por domínio:

- **8 especialistas por épico** (E02–E09)
- **3 transversais** (metodologia de irrigação, UX/DX, PMO técnico)

Todos **read-only no MVP**: `tools: Read, Grep, Glob` (sem Bash, sem Edit/Write/NotebookEdit). Frase canônica obrigatória em cada prompt: *"Você é um subagent especialista OPCIONAL. Você NÃO substitui slash commands, aprovação humana, RT, engenheiro, agrônomo ou decisão executiva."* validada por T-AGT-5.

**Total no repositório:** 15 agentes (4 governança TOOL-005 + 8 especialistas + 3 transversais TOOL-006).

**Política preservada:** ADR-016 cobre toda a política permanente de subagents — **sem ADR nova**. Sem integração automática a slash commands. Smoke live dos 11 novos adiado para **TOOL-006A futura** (registry só recarrega pós-commit — descoberta documentada em TOOL-005 §5.1).

```javascript
const GOVERNANCE_AGENTS = [/* 4 nomes — TOOL-005 */];

const SPECIALIST_AGENTS = [
  "architecture-layout-agent", "hydraulics-agent",
  "constructability-agent", "bom-catalog-agent",
  "map-workspace-agent", "proposal-pdf-agent",
  "commercial-engine-agent", "field-validation-agent",
];

const CROSS_FUNCTIONAL_AGENTS = [
  "irrigation-methodology-agent",

  "software-project-manager-agent",
];

const TOOL_006_AGENTS = [...SPECIALIST_AGENTS, ...CROSS_FUNCTIONAL_AGENTS]; // 11

const AGENTS = [...GOVERNANCE_AGENTS, ...TOOL_006_AGENTS];                  // 15

const READ_ONLY_AGENTS = [
  "context-gate-agent", "test-qa-agent", "close-commit-agent",
  ...TOOL_006_AGENTS,                                                       // 14 total
];
```

**Novo T-AGT-8** valida via `assert.deepEqual` em set sorted:

```javascript
test("T-AGT-8: agents da TOOL-006 (11) têm tools exatamente Read, Grep, Glob", () => {
  const EXPECTED_TOOLS = ["Read", "Grep", "Glob"];
  for (const name of TOOL_006_AGENTS) {
    const tools = toolsList(parseFrontmatter(readAgent(name).content));
    assert.deepEqual(
      [...tools].sort(),
      [...EXPECTED_TOOLS].sort(),
      `${name} tools deve ser exatamente Read, Grep, Glob (sem Bash, sem extras). Atual: ${tools.join(", ")}`
    );
  }
});
```

Set equality previne regressão silenciosa (ex.: alguém adicionar `Bash` em PR futura).

## 10. ADR necessária?

**Não.** ADR-016 (criada em TOOL-005) cobre toda a política permanente de subagents:
- §3: "Restrição de permissões via campo `tools`" → satisfeito por `Read, Grep, Glob` em todos os 11 novos
- §4: "Subagent NÃO decide criticamente sozinho" → satisfeito pela frase canônica + proibições absolutas + formato de resposta como "parecer/diagnóstico"
- §6: "Subagent NÃO commita nem pusha sem aprovação humana" → satisfeito pela ausência mecânica de Bash em todos os 11
- §8: "Frase de proteção `NÃO substitui` obrigatória" → validada por T-AGT-5

Qualquer subagent novo no futuro segue a mesma política sob ADR-016. Apenas integração de subagent em slash command (futura TOOL-007) pode requerer emenda à ADR-016 ou ADR nova — fora do escopo desta task.
