## Decisões tomadas

| Decisão | Alternativa descartada | Motivo |
|---------|----------------------|--------|
| Peso `WEIGHT_LATERAL_LENGTH = 0` (inativo) | Aplicar penalidade com normalização heurística `totalLateralLengthM / (sprinklerCount × spacingMeters)` | Normalização pode produzir penalidade pouco informativa entre candidatos do mesmo polígono — candidatos variam pouco no total por serem da mesma área; aguardar calibração RT de campo |
| Campos `number` (não-nullable) | `number \| null` | Métricas geométricas puras — sempre computáveis a partir de `physicalColumns.comprimentoM`; não dependem de `nSetores` ou `waterSource` |
| Zero-path retorna 0 para todos os campos de laterais | retornar null | Coerência com tipo `number`; candidatos sem aspersores têm comprimento = 0 (correto matematicamente) |
| `lateralLengthPerHectareM` via `areaM2` já calculada | Chamar `turf.area` novamente | `areaM2` já estava disponível no escopo de `computeScore` para calcular `fillingRatio`; reaproveitamento sem custo de performance |
