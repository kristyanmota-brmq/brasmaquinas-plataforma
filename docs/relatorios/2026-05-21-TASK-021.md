  1. `import Link from "next/link"` adicionado

  3. Destructuring: `statusLabel` extraído; estado `sidebarOpen` adicionado

## Decisões tomadas

| Decisão | Alternativa descartada | Motivo |
|---------|----------------------|--------|
| Blockers derivados de `projectResult.diagnostics` (sempre reativos) | Só mostrar quando `pdfError` é populado | Diagnóstico deve ser visível a qualquer momento, não apenas após tentar PDF |
| `100dvh` em vez de `100vh` | `100vh` simples | Em mobile/Safari, `100vh` inclui a barra do navegador e gera overflow visual |
| Sidebar como drawer `fixed` em mobile | Grid de 1 coluna com sidebar abaixo | Drawer não empurra o mapa para baixo — mapa permanece full-height |
| `pdfError` mantido como estado | Remover completamente | `invalidHydraulicSegments` e erro técnico inesperado ainda dependem do estado |
| Overlay `bg-black/30` fecha ao clicar fora | Botão X explícito de fechar | Padrão de UI mais intuitivo para drawers/modals |
| `BlockerSection.tsx` não criado | Extrair em componente separado | Seção simples, sem lógica própria — inline no aside é suficiente |
| `page.tsx` sem `min-h-screen` | Manter `min-h-screen` | ProjectMap preenche `100dvh - 64px`; `min-h-screen` seria redundante |
